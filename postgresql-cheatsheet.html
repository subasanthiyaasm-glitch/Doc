Getting Started

Check the installed PostgreSQL server version with psql --version. W3Schools →
Version
-- Check PostgreSQL version
psql --version
psql (PostgreSQL) 16.2
Connect to the PostgreSQL interactive terminal as the superuser postgres. W3Schools →
Connect as postgres
sudo -u postgres psql
psql (16.2)
Type "help" for help.
postgres=#
List all databases on the PostgreSQL server using the \l meta-command. W3Schools →
List Databases
\l
List of databases
Name | Owner | Encoding
-----------+-------+----------
postgres | postgres | UTF8
template0 | postgres | UTF8
template1 | postgres | UTF8
Switch to a specific database with \c followed by the database name. W3Schools →
Connect to Database
\c postgres
You are now connected to database "postgres".
Exit psql with \q or run a shell command without leaving psql using \!. W3Schools →
Quit & Shell Escape
\q    -- quit psql
\!    -- shell escape
\q → exits psql
\! ls → runs shell command
Common command-line options for the psql client tool. W3Schools →
psql Command Options
-d mydb    -- database name
-U user    -- user name
-h host    -- host
-p port    -- port
-W          -- force password
-c "SQL"  -- run single command
-H          -- HTML output
-l          -- list databases
-f file    -- execute file
-V          -- version
OptionExample
-dpsql -d mydb
-Upsql -U user -h host -p port
-U -h -p -dpsql -U user -h host -p port -d db
-Wpsql -W -U user -d db
-cpsql -c "SELECT 1"
-Hpsql -H -c "SELECT 1"
-lpsql -l
-fpsql -f file.sql
-Vpsql -V

Backup & Restore

Back up all PostgreSQL databases to a single SQL file using pg_dumpall. W3Schools →
Dump All Databases
pg_dumpall -U postgres > all.sql
Dumps all databases to all.sql
(no output on success)
Back up a specific database to a SQL file using pg_dump. W3Schools →
Dump Single Database
pg_dump -d mydb -f mydb_backup.sql
(no output on success)
Common flags for pg_dump to control what gets included in the backup. W3Schools →
pg_dump Options
pg_dump -a     -- data only
pg_dump -s     -- schema only
pg_dump -c     -- include DROP
pg_dump -C     -- include CREATE
pg_dump -t tbl -- specific table
pg_dump -F c   -- custom format
OptionDescription
-adata only (no schema)
-sschema only (no data)
-cinclude DROP statements
-Cinclude CREATE DATABASE
-tdump specific table
-Foutput format (c/d/t/p)
Restore a database from a plain SQL dump file using psql with input redirection. W3Schools →
Restore SQL Dump
psql -U user mydb < mydb_backup.sql
SET
CREATE TABLE
INSERT 0 1
Restore a custom-format dump using pg_restore with the -c clean option. W3Schools →
Restore with pg_restore
pg_restore -d mydb mydb_backup.sql -c
(no output on success)
Common flags for pg_restore to control restore behavior. W3Schools →
pg_restore Options
pg_restore -U user   -- user
pg_restore -c        -- clean (DROP before restore)
pg_restore -C        -- create database
pg_restore -e        -- exit on error
pg_restore -F c      -- custom format
OptionDescription
-Udatabase user
-cclean (drop before restore)
-Ccreate database
-eexit on error
-Fformat (c/d/t)

Remote Access

Find the path to the main PostgreSQL configuration file using SHOW config_file. W3Schools →
Find Config File
SHOW config_file;
config_file
--------------------------------------
/etc/postgresql/16/main/postgresql.conf
Set the listen_addresses option in postgresql.conf to accept remote connections. W3Schools →
Listen Addresses
# postgresql.conf
listen_addresses = '*'
Allows connections from any IP
Add host-based authentication rules in pg_hba.conf to allow remote client access. W3Schools →
pg_hba.conf Entries
# pg_hba.conf — add before existing rules
host    all    all    192.168.1.0/24    md5
host    all    all    0.0.0.0/0         md5

Restart PostgreSQL
