Joins


      

        A JOIN combines rows from two tables where a condition holds — usually a foreign key equal to a primary key, as in orders.user_id = users.id.
        W3Schools →
      

      

        

          
INNER JOIN

          
SELECT u.name, o.total
  FROM users u
  JOIN orders o ON o.user_id = u.id;

        

        

          

            

               name | total

              ------+-------

               Ava  | 40.00

               Ben  | 15.50

               Ava  | 72.00
            

          

        

      


      

        Which rows survive depends on the join type. In each Venn the left circle is users, the right is orders, and the shaded area is what the query returns.
        W3Schools →
      

      

        

          

            
INNER JOIN

            
            
Only rows that match on both sides — users who have placed an order.

          

          

            
LEFT JOIN

            
            
All users, matched or not; a user with no order gets NULL order columns.

          

          

            
RIGHT JOIN

            
            
All orders, matched or not; an order with no user gets NULL user columns.

          

          

            
FULL OUTER JOIN

            
            
Every row from both tables; NULL fills whichever side has no match.
