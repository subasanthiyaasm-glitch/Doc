OpenCode

OpenCode — AI Coding Agent

Terminal-based AI coding assistant. Works with local & cloud models. Executes tasks autonomously in your shell.

CLI Commands
opencode          # Start interactive session
opencode --model gpt-4  # Choose model
opencode --help       # Show help
opencode --version    # Show version
/help                      # In-session help
/model claude-sonnet   # Switch model mid-session
/clear                     # Clear conversation
/exit                      # Exit session
/task "refactor X"     # Run autonomous task
Pro Tips
⚡ Use Ctrl+C to interrupt a long response
🔁 /model switches models without restarting
📎 Drag & drop files into terminal to attach context
🌐 Use webfetch skill to scrape live URLs
🧩 Load skills with the skill tool
Supported Models
gpt-4o          # OpenAI
gpt-4o-mini      # OpenAI (fast)
claude-sonnet-4  # Anthropic
claude-haiku     # Anthropic (fast)
gemini-2.5-pro   # Google
gemini-2.5-flash # Google (fast)
deepseek         # DeepSeek
llama-3.1        # Meta (local)
QwQ-32B          # Qwen (local)
Key Concepts
Skills — Specialized instruction files loaded per-task
Sub-agents — Delegate complex/multi-step work to child agents
Tools — Bash, file read/write, search, web fetch, browser automation
Permissions — Granular allow/deny per command or tool
ChatGPT

ChatGPT — OpenAI

General-purpose conversational AI. Supports browsing, code execution, image generation, and file uploads.

Key Features
# Prompting tips
System prompt: "You are a senior Python dev"
One-shot:      Give one example → ask
Chain-of-thought: "Let's think step by step"
Role-play:     "Act as a code reviewer..."

# Capabilities
Code execution    — Python sandbox (Advanced Data Analysis)
Image gen         — DALL·E 3 (via GPT-4)
Web browsing      — Live search (manual enable)
File upload       — PDF, image, code, CSV, ZIP
Memory            — Persistent user preferences
Custom GPTs       — Tailored assistants per domain
Best For
✅ Brainstorming & creative writing
✅ Data analysis with uploaded CSVs
✅ Learning new topics via dialogue
✅ Generating images from descriptions
⚠️ Large codebases — context window limits apply
Gemini

Gemini — Google DeepMind

Multimodal AI with massive context window. Native integration with Google ecosystem.

Key Features
# Prompting tips
System instruction:  Set persona via Gemini API
Structured output:   Request JSON schema response
Grounding:           "Search Google for..."

# Capabilities
1M context          — Gemini 1.5 Pro (huge docs)
Video analysis      — Upload video, ask questions
Audio processing    — Transcribe & analyze audio
Google integration  — Gmail, Docs, Drive, Maps
Code execution      — Python sandbox (Gemini Advanced)
Function calling    — API mode for tool use
Best For
✅ Processing massive documents (1M tokens)
✅ Video & multimodal analysis
✅ Google Workspace automation
✅ Research paper digestion
⚠️ Less effective at complex code generation vs GPT-4/Claude
Claude

Claude — Anthropic

Safety-focused AI with strong coding and reasoning abilities. Excellent at long-form analysis.

Key Features
# Prompting tips
System prompt:  Use for persona & constraints
XML tags:       Structure input with <task> <code> <context>
Few-shot:       Show 2-3 examples for formatting
Chain-of-thought: Natural in Claude's responses

# Capabilities
200K context        — Claude 3.5 Sonnet
Code generation     — Excellent at complex logic
Artifacts           — Side-by-side document/code preview
Projects            — Knowledge base per project
API tool use        — Let Claude call your functions
Vision              — Image analysis (charts, diagrams)
Style control       — Verbosity, tone, format guidelines
Best For
✅ Complex code architecture & refactoring
✅ Long-form writing & analysis
✅ Following detailed style & format instructions
✅ Reading & summarizing large codebases
⚠️ No native image generation or web search
