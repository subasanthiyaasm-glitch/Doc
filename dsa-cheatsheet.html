Linked List

Dynamic size chain of nodes. O(1) insert/delete at head; O(n) access by index (no random access). W3Schools →
LinkedList.java
class ListNode {
  int val;
  ListNode next;
  ListNode(int val) { this.val = val; }
}

// Singly Linked List
class SinglyLinkedList {
  ListNode head;
  int size = 0;

  // Insert at head — O(1)
  void addFirst(int val) {
    ListNode node = new ListNode(val);
    node.next = head;
    head = node;
    size++;
  }

  // Remove at head — O(1)
  int removeFirst() {
    if (head == null) throw new NoSuchElementException();
    int val = head.val;
    head = head.next;
    size--;
    return val;
  }

  // Search — O(n)
  boolean contains(int val) {
    ListNode cur = head;
    while (cur != null) {
      if (cur.val == val) return true;
      cur = cur.next;
    }
    return false;
  }
}

Two Pointer Technique — fast/slow pointers to detect cycles and find middle of linked list.
TwoPointers.java
// Detect cycle — Floyd's algorithm
boolean hasCycle(ListNode head) {
  ListNode slow = head, fast = head;
  while (fast != null && fast.next != null) {
    slow = slow.next;
    fast = fast.next.next;
    if (slow == fast) return true;
  }
  return false;
}

// Find middle node
ListNode findMiddle(ListNode head) {
  ListNode slow = head, fast = head;
  while (fast.next != null && fast.next.next != null) {
    slow = slow.next;
    fast = fast.next.next;
  }
  return slow;
}

// Reverse linked list — O(n) time, O(1) space
ListNode reverse(ListNode head) {
  ListNode prev = null, cur = head;
  while (cur != null) {
    ListNode next = cur.next;
    cur.next = prev;
    prev = cur;
    cur = next;
  }
  return prev;
}

Two Sum pattern — classic hashmap usage for complementary lookups in O(n).
TwoSum.java
// Find two indices that sum to target — O(n)
int[] twoSum(int[] nums, int target) {
  HashMap<Integer, Integer> seen = new HashMap<>();
  for (int i = 0; i < nums.length; i++) {
    int complement = target - nums[i];
    if (seen.containsKey(complement)) {
      return new int[] { seen.get(complement), i };
    }
    seen.put(nums[i], i);
  }
  return new int[0];
}

Trees & BST

Binary Tree — each node has at most 2 children. BST — left < root < right. Inorder traversal gives sorted order. W3Schools →
BinarySearchTree.java
class TreeNode {
  int val;
  TreeNode left, right;
  TreeNode(int val) { this.val = val; }
}

class BST {
  TreeNode root;

  // Insert — O(log n) average
  TreeNode insert(TreeNode node, int val) {
    if (node == null) return new TreeNode(val);
    if (val < node.val)
      node.left = insert(node.left, val);
    else if (val > node.val)
      node.right = insert(node.right, val);
    return node;
  }

  // Search — O(log n) average
  boolean search(TreeNode node, int val) {
    if (node == null) return false;
    if (val == node.val) return true;
    if (val < node.val) return search(node.left, val);
    return search(node.right, val);
  }

  // Inorder traversal — O(n) — yields sorted order
  void inorder(TreeNode node) {
    if (node == null) return;
    inorder(node.left);
    System.out.println(node.val);
    inorder(node.right);
  }
}

BFS Level-order Traversal — visit nodes level by level using a queue.
BFSTraversal.java
List<List<Integer>> levelOrder(TreeNode root) {
  List<List<Integer>> result = new ArrayList<>();
  if (root == null) return result;

  Queue<TreeNode> queue = new ArrayDeque<>();
  queue.offer(root);

  while (!queue.isEmpty()) {
    int levelSize = queue.size();
    List<Integer> level = new ArrayList<>();

    for (int i = 0; i < levelSize; i++) {
      TreeNode node = queue.poll();
      level.add(node.val);
      if (node.left != null) queue.offer(node.left);
      if (node.right != null) queue.offer(node.right);
    }
    result.add(level);
  }
  return result;
}

// Max depth — O(n)
int maxDepth(TreeNode root) {
  if (root == null) return 0;
  return 1 + Math.max(
    maxDepth(root.left),
    maxDepth(root.right)
  );
}

BFS — shortest path in unweighted graphs. DFS — explores all paths, cycle detection, topological sort.
BFS.java
// BFS — Shortest path in unweighted graph
int[] bfs(Map<Integer,List<Integer>> adj, int start) {
  int n = adj.size();
  int[] dist = new int[n];
  Arrays.fill(dist, -1);
  dist[start] = 0;

  Queue<Integer> queue = new ArrayDeque<>();
  queue.offer(start);

  while (!queue.isEmpty()) {
    int u = queue.poll();
    for (int v : adj.getOrDefault(u, List.of())) {
      if (dist[v] == -1) {
        dist[v] = dist[u] + 1;
        queue.offer(v);
      }
    }
  }
  return dist;
}

// Complexity: O(V + E)

// DFS — Recursive
void dfs(Map<Integer,List<Integer>> adj, int u, boolean[] visited) {
  visited[u] = true;
  System.out.print(u + " ");
  for (int v : adj.getOrDefault(u, List.of())) {
    if (!visited[v]) dfs(adj, v, visited);
  }
}

// Detect cycle in undirected graph
boolean hasCycle(Map<Integer,List<Integer>> adj, int u, boolean[] visited, int parent) {
  visited[u] = true;
  for (int v : adj.getOrDefault(u, List.of())) {
    if (!visited[v]) {
      if (hasCycle(adj, v, visited, u)) return true;
    } else if (v != parent) {
      return true;
    }
  }
  return false;
}

Quick Sort — divide and conquer with in-place partitioning. Most-used general-purpose sort.
QuickSort.java
void quickSort(int[] arr, int low, int high) {
  if (low < high) {
    int pivot = partition(arr, low, high);
    quickSort(arr, low, pivot - 1);
    quickSort(arr, pivot + 1, high);
  }
}

int partition(int[] arr, int low, int high) {
  int pivot = arr[high];  // Lomuto partition
  int i = low - 1;
  for (int j = low; j < high; j++) {
    if (arr[j] <= pivot) {
      i++;
      int temp = arr[i]; arr[i] = arr[j]; arr[j] = temp;
    }
  }
  int temp = arr[i+1]; arr[i+1] = arr[high]; arr[high] = temp;
  return i + 1;
}

// Best: O(n log n), Worst: O(n²) — already sorted input
// Mitigate: randomize pivot or use median-of-three

Searching Algorithms

Linear Search — check every element, O(n). Binary Search — halve the search space, O(log n) on sorted data. W3Schools →
BinarySearch.java
// Binary Search — O(log n) — must be sorted
int binarySearch(int[] arr, int target) {
  int lo = 0, hi = arr.length - 1;
  while (lo <= hi) {
    int mid = lo + (hi - lo) / 2;  // avoid overflow
    if (arr[mid] == target) return mid;
    else if (arr[mid] < target) lo = mid + 1;
    else hi = mid - 1;
  }
  return -1;  // not found
}

// Lower bound — first index where arr[idx] >= target
int lowerBound(int[] arr, int target) {
  int lo = 0, hi = arr.length;
  while (lo < hi) {
    int mid = lo + (hi - lo) / 2;
    if (arr[mid] < target) lo = mid + 1;
    else hi = mid;
  }
  return lo;
}

// Upper bound — first index where arr[idx] > target
int upperBound(int[] arr, int target) {
  int lo = 0, hi = arr.length;
  while (lo < hi) {
    int mid = lo + (hi - lo) / 2;
    if (arr[mid] <= target) lo = mid + 1;
    else hi = mid;
  }
  return lo;
}

Dynamic Programming

Memoization (Top-Down)

Recursion + cache. Write the recursive solution first, then store results in a HashMap/array to avoid recomputation. Easier to think about.

Tabulation (Bottom-Up)

Iterative, fill a table from base cases up. Eliminates recursion stack. Often more space-efficient with rolling array optimization.

Fibonacci — classic DP example. Naive recursion is O(2⊃n); DP makes it O(n). W3Schools →
Fibonacci.java
// ❌ Naive recursion — O(2^n) time, O(n) stack
long fibNaive(int n) {
  if (n <= 1) return n;
  return fibNaive(n-1) + fibNaive(n-2);
}

// ✅ Memoization (Top-Down) — O(n) time, O(n) space
long fibMemo(int n, long[] memo) {
  if (n <= 1) return n;
  if (memo[n] != 0) return memo[n];
  memo[n] = fibMemo(n-1, memo) + fibMemo(n-2, memo);
  return memo[n];
}

// ✅ Tabulation (Bottom-Up) — O(n) time, O(n) space
long fibTab(int n) {
  if (n <= 1) return n;
  long[] dp = new long[n + 1];
  dp[0] = 0; dp[1] = 1;
  for (int i = 2; i <= n; i++) {
    dp[i] = dp[i-1] + dp[i-2];
  }
  return dp[n];
}

// ✅ Space-optimized — O(n) time, O(1) space
long fibOpt(int n) {
  if (n <= 1) return n;
  long a = 0, b = 1;
  for (int i = 2; i <= n; i++) {
    long c = a + b;
    a = b;
    b = c;
  }
  return b;
}
▶ Memoization vs Tabulation
Memoization (Top-Down)
Start from n, recurse down
Lazily computes only needed states
Easier to convert from recursion
Tabulation (Bottom-Up)
Start from 0, build up to n
Computes all states
No recursion stack overhead
Easier to optimize space (rolling)
Both give same time complexity
Coin Change — given coins and a target amount, find the minimum number of coins needed.
CoinChange.java
// Minimum coins to make amount — O(amount * coins)
int coinChange(int[] coins, int amount) {
  int[] dp = new int[amount + 1];
  Arrays.fill(dp, amount + 1);  // "infinity"
  dp[0] = 0;

  for (int i = 1; i <= amount; i++) {
    for (int coin : coins) {
      if (coin <= i && dp[i - coin] + 1 < dp[i]) {
        dp[i] = dp[i - coin] + 1;
      }
    }
  }
  return dp[amount] > amount ? -1 : dp[amount];
}

// Example: coins=[1,5,10,25], amount=30
// Result: 2 coins (25 + 5)

Trie (Prefix Tree)

Prefix tree — stores strings character by character. O(L) insert/search where L = word length. Used for autocomplete and spell checking. W3Schools →
Trie.java
class TrieNode {
  TrieNode[] children = new TrieNode[26];
  boolean isEnd = false;
}

class Trie {
  TrieNode root = new TrieNode();

  // Insert — O(L)
  void insert(String word) {
    TrieNode node = root;
    for (char c : word.toCharArray()) {
      int idx = c - 'a';
      if (node.children[idx] == null)
        node.children[idx] = new TrieNode();
      node = node.children[idx];
    }
    node.isEnd = true;
  }

  // Search — O(L)
  boolean search(String word) {
    TrieNode node = findPrefix(word);
    return node != null && node.isEnd;
  }

  // Starts with — O(L)
  boolean startsWith(String prefix) {
    return findPrefix(prefix) != null;
  }

  private TrieNode findPrefix(String s) {
    TrieNode node = root;
    for (char c : s.toCharArray()) {
      int idx = c - 'a';
      if (node.children[idx] == null) return null;
      node = node.children[idx];
    }
    return node;
  }
}

Bloom Filter

Probabilistic data structure. Says "definitely not in set" or "probably in set". O(k) lookup where k = number of hash functions. Never has false negatives.
BloomFilter.java
class BloomFilter {
  private final boolean[] bitArray;
  private final int size;
  private final int numHashes;

  BloomFilter(int expectedItems, double fpr) {
    // optimal size: -(n * ln(p)) / (ln2)²
    this.size = (int)(-expectedItems * Math.log(fpr) / (Math.log(2) * Math.log(2)));
    this.numHashes = (int)(Math.log(2) * size / expectedItems);
    bitArray = new boolean[size];
  }

  // Hash functions using different seeds
  private int hash(String val, int seed) {
    int h = seed;
    for (char c : val.toCharArray()) {
      h = h * 31 + c;
    }
    return Math.abs(h) % size;
  }

  // Add — O(k)
  void add(String val) {
    for (int i = 0; i < numHashes; i++) {
      bitArray[hash(val, i)] = true;
    }
  }

  // Might contain — O(k) — NO false negatives
  boolean mightContain(String val) {
    for (int i = 0; i < numHashes; i++) {
      if (!bitArray[hash(val, i)]) return false;
    }
    return true;  // might be false positive
  }
}

// Usage
BloomFilter bf = new BloomFilter(1000000, 0.01); // 1M items, 1% FPR
bf.add("user@example.com");
bf.mightContain("user@example.com"); // true (always)
bf.mightContain("other@test.com");  // false (probably)

Bellman-Ford Algorithm

Single-source shortest path algorithm that handles negative edge weights and detects negative weight cycles. Runs in O(VE) time. W3Schools →
BellmanFord.java
class Edge {
  int src, dest, weight;
  Edge(int s, int d, int w) {
    src = s; dest = d; weight = w;
  }
}

void bellmanFord(Edge[] edges, int V, int src) {
  int[] dist = new int[V];
  Arrays.fill(dist, Integer.MAX_VALUE);
  dist[src] = 0;

  // Relax edges V-1 times
  for (int i = 1; i < V; i++) {
    for (Edge e : edges) {
      if (dist[e.src] != Integer.MAX_VALUE
          && dist[e.src] + e.weight < dist[e.dest]) {
        dist[e.dest] = dist[e.src] + e.weight;
      }
    }
  }

  // Check for negative-weight cycles
  for (Edge e : edges) {
    if (dist[e.src] != Integer.MAX_VALUE
        && dist[e.src] + e.weight < dist[e.dest]) {
      System.out.println("Negative cycle detected");
      return;
    }
  }

  for (int i = 0; i < V; i++) {
    System.out.println(i + " → " + dist[i]);
  }
}

// Time:  O(V × E)
// Space: O(V)
▶ How It Works
Steps
1. Init dist[src] = 0, all others = ∞
2. Repeat V-1 times: relax all edges
3. One more pass — if dist improves, negative cycle
Key Properties
Handles negative edge weights ✓
Detects negative-weight cycles ✓
Edge list representation
When to Use
Graph has negative weights
Need to detect negative cycles
Single-source shortest path

Dijkstra's Algorithm

Single-source shortest path for graphs with non-negative weights. Uses a priority queue for O((V+E) log V) time. Greedy approach. W3Schools →
Dijkstra.java
void dijkstra(List<List<int[]>> adj, int src) {
  int V = adj.size();
  int[] dist = new int[V];
  Arrays.fill(dist, Integer.MAX_VALUE);
  dist[src] = 0;

  // PriorityQueue stores {distance, vertex}
  PriorityQueue<int[]> pq = new PriorityQueue<>(
    Comparator.comparingInt(a -> a[0])
  );
  pq.offer(new int[] {0, src});

  while (!pq.isEmpty()) {
    int[] cur = pq.poll();
    int d = cur[0], u = cur[1];
    if (d > dist[u]) continue;  // stale entry

    for (int[] edge : adj.get(u)) {
      int v = edge[0], w = edge[1];
      if (dist[u] + w < dist[v]) {
        dist[v] = dist[u] + w;
        pq.offer(new int[] {dist[v], v});
      }
    }
  }
}

// Time:  O((V + E) log V) with binary heap
// Space: O(V)
▶ How It Works
Greedy Strategy
1. Init dist[src] = 0, all others = ∞
2. Pick unvisited vertex with smallest dist
3. Relax all its neighbors
4. Repeat until PQ is empty
Constraints
Non-negative edge weights only ✗
No negative cycle detection
When to Use
Weighted graph, non-negative edges
Single-source shortest path
Faster than Bellman-Ford

Floyd-Warshall Algorithm

All-pairs shortest path using dynamic programming. Works with negative edges (not negative cycles). Runs in O(V³) time, O(V²) space. W3Schools →
FloydWarshall.java
void floydWarshall(int[][] graph) {
  int V = graph.length;
  int[][] dist = new int[V][V];

  // Init dist matrix from graph
  for (int i = 0; i < V; i++) {
    for (int j = 0; j < V; j++) {
      dist[i][j] = graph[i][j];
    }
  }

  // k = intermediate vertex
  for (int k = 0; k < V; k++) {
    for (int i = 0; i < V; i++) {
      for (int j = 0; j < V; j++) {
        if (dist[i][k] != Integer.MAX_VALUE
            && dist[k][j] != Integer.MAX_VALUE) {
          dist[i][j] = Math.min(dist[i][j],
              dist[i][k] + dist[k][j]);
        }
      }
    }
  }

  // Print shortest path matrix
  for (int[] row : dist) {
    System.out.println(Arrays.toString(row));
  }
}

// Time:  O(V³)
// Space: O(V²)
▶ How It Works
DP Recurrence
dist[i][j] = min(dist[i][j],
             dist[i][k] + dist[k][j])
Key Properties
All-pairs shortest paths
Handles negative edges
Does NOT handle negative cycles
Very simple 3-loop implementation
When to Use
Dense graphs (V small)
Need shortest paths between ALL pairs
Transitive closure variant

Hashing Concepts

Hash functions map keys to bucket indices. O(1) average lookup. Collision handling via chaining or open addressing. Load factor triggers resize. W3Schools →

// Java's String.hashCode(): h = s[0]*31^(n-1) + ... + s[n-1]
int hash(String key) {
  int h = 0;
  for (char c : key.toCharArray()) {
    h = h * 31 + c;
  }
  return h;
}

int idx = hash & (capacity - 1);  // same as hash % capacity

// Default capacity: 16, load factor: 0.75

map.get("hello");            // O(1) avg
map.containsKey("hello");  // O(1) avg

// HashSet — backed by HashMap with dummy value
HashSet<String> set = new HashSet<>();

// Override hashCode + equals for custom objects
class Person {
  String name;
  int age;

  public int hashCode() {
    return Objects.hash(name, age);
  }

  public boolean equals(Object o) {
    if (this == o) return true;
    if (!(o instanceof Person)) return false;
    Person p = (Person) o;
    return age == p.age && name.equals(p.name);
  }
}
▶ Collision Handling
Separate Chaining (Java)
Each bucket → linked list or tree
Chain > 8 → treeify (O(log n))
Open Addressing
Linear probe: (h+1)%n, (h+2)%n...
Quadratic probe: h+i²
Double hash: h1+i×h2
Load Factor & Resize
Default threshold: 0.75
Resize = double capacity, rehash all
Cost: O(n) amortized per insert
DP Algorithm

Partition Equal Subset Sum

Given an array, determine if it can be split into two subsets with equal sum. Reduce to subset sum = totalSum/2. Uses 1D boolean DP in O(n × target). W3Schools →
PartitionEqualSubset.java
boolean canPartition(int[] nums) {
  int total = 0;
  for (int num : nums) total += num;

  // Odd total → impossible to split equally
  if (total % 2 != 0) return false;

  int target = total / 2;
  boolean[] dp = new boolean[target + 1];
  dp[0] = true;  // zero sum always possible

  for (int num : nums) {
    // Traverse right-to-left to avoid reuse
    for (int i = target; i >= num; i--) {
      dp[i] = dp[i] || dp[i - num];
    }
  }

  return dp[target];
}

// Example: [1, 5, 11, 5]
// total = 22, target = 11
// Subsets: [11] and [1, 5, 5] → true

// Time:  O(n × target)
// Space: O(target)
▶ DP Walkthrough
Key Insight
If totalSum is odd → return false
Otherwise find subset with sum = total/2
dp[i] = can we make sum i?
Init: dp[0] = true
For each num: update dp[target → num]
Right-to-left prevents counting same num twice

Amortized analysis, Master theorem, and recurrence relations — advanced tools for analyzing algorithm efficiency beyond basic Big O.
Amortized & Recurrences
// ── Amortized Analysis ──
// Average cost over a sequence of operations
// ArrayList.add(): usually O(1), occasionally O(n)
// → amortized O(1) per operation
ArrayList<Integer> list = new ArrayList<>();
for (int i = 0; i < 1000000; i++) {
  list.add(i);  // amortized O(1)
}

// ── Master Theorem ──
// For T(n) = aT(n/b) + O(n^d):
//   Case 1: log_b(a) > d → O(n^log_b(a))
//   Case 2: log_b(a) = d → O(n^d × log n)
//   Case 3: log_b(a) < d → O(n^d)
//
// Examples:
// Merge Sort: T(n)=2T(n/2)+O(n)
//   a=2, b=2, d=1 → log₂2=1=d → Case 2
//   → O(n log n)
//
// Binary Search: T(n)=T(n/2)+O(1)
//   a=1, b=2, d=0 → log₂1=0=d → Case 2
//   → O(log n)

// ── Recurrence Relations ──
// T(n) = T(n-1) + O(n) → O(n²)  (selection sort)
// T(n) = T(n-1) + O(1) → O(n)   (linked list traversal)
// T(n) = 2T(n-1) + O(1) → O(2ⁿ) (tower of hanoi)
// T(n) = T(n/2) + O(1) → O(log n) (binary search)
// T(n) = 2T(n/2) + O(n) → O(n log n) (merge sort)
