How CSS Works

HTML builds the page; CSS decides how it looks. You write a rule that picks an element (a selector) and gives it properties like color or size.

1. A rule finds an element and styles it

.hello { color: teal; font-size: 2rem; }
→

Hello!

The selector .hello picks the element, then the properties apply — watch the word turn teal and grow.

2. Every element is a set of boxes

margin
border
padding
content

The box model: content sits inside padding, wrapped by a border, with margin as space outside — each lights up in turn.
