Getting Started

CSS is rich in capabilities and is more than simply laying out pages.

Link an external CSS file from HTML using <link> in the <head>. W3Schools →
External stylesheet
<head>
  <link href="./style.css" rel="stylesheet" />
</head>
Linked CSS loads from external file
Embed CSS directly inside an HTML page using a <style> tag. W3Schools →
Internal stylesheet
<style>
  .demo-card { background: linen; padding: 0.5rem; }
</style>
Styled via internal <style> tag
Apply CSS directly to an HTML element using the style attribute. W3Schools →
Inline styles
<h2 style="text-align:center;">Centered text</h2>
<p style="color:blue;font-size:18px;">Blue 18px text</p>

Centered text

Blue, 18-point text

Assign CSS classes to elements and use !important to override other styles. W3Schools →
Classes & !important
<div class="classname"></div>
<div class="class1 class2"></div>

.post-title { color: blue !important; }

!important overrides all previous styling.

CSS Animation

Create reusable animations with @keyframes and apply them using the animation property. W3Schools → 
@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-10px); }
}

.box {
  animation: bounce 500ms ease infinite;
}
