How Java Runs: Write Once, Run Anywhere

You write Main.java, javac turns it into portable Main.class bytecode, and the JVM runs that bytecode on Windows, macOS, or Linux. Watch the dot flow through each step. W3Schools →

Servlet

HttpServlet handles HTTP requests via doGet() and doPost() methods; the container manages request/response objects. W3Schools →
HttpServlet
import javax.servlet.*;
import javax.servlet.http.*;
import java.io.*;

public class MyServlet extends HttpServlet {

  protected void doGet(HttpServletRequest req,
      HttpServletResponse resp)
      throws IOException {
    resp.setContentType("text/html");
    PrintWriter out = resp.getWriter();
    out.println("<h1>GET OK</h1>");
  }

  protected void doPost(HttpServletRequest req,
      HttpServletResponse resp)
      throws IOException {
    String name = req.getParameter("name");
    resp.getWriter().println("Hello " + name);
  }
}
▶ Preview

// HttpServletRequest & Response
GET → doGet()

JDBC

JDBC (Java Database Connectivity) connects Java apps to databases via DriverManager and standard SQL operations. W3Schools →
Connection Steps
import java.sql.*;

// 1. Load driver
Class.forName("com.mysql.cj.jdbc.Driver");

// 2. Get connection
Connection con = DriverManager.getConnection(
    "jdbc:mysql://localhost:3306/login",
    "root", "root");

// 3. Create statement
PreparedStatement stmt = con.prepareStatement(
    "SELECT * FROM Emp WHERE name = ?");

// 4. Execute query
stmt.setString(1, "arun");
ResultSet rs = stmt.executeQuery();

// 5. Process results
while(rs.next()) {
  String name = rs.getString("name");
}

// 6. Close resources
con.close();
▶ Preview
// JDBC Steps:
1. Load Driver
2. Connection
3. PreparedStatement
4. Execute → ResultSet
5. Process → Close
PreparedStatement pre-compiles SQL with ? placeholders, preventing SQL injection and improving performance. W3Schools →
INSERT / UPDATE / Batch
// INSERT with PreparedStatement
PreparedStatement ins = con.prepareStatement(
    "INSERT INTO Emp VALUES(?, ?)");
ins.setString(1, "arun");
ins.setString(2, "value2");
ins.executeUpdate();

// UPDATE
PreparedStatement upd = con.prepareStatement(
    "UPDATE Emp SET salary = ? WHERE id = ?");
upd.setInt(1, 50000);
upd.setInt(2, 123);
upd.executeUpdate();

// Batch inserts
PreparedStatement batch = con.prepareStatement(
    "INSERT INTO Emp VALUES(?, ?)");
batch.setString(1, "user1");
batch.setString(2, "data1");
batch.addBatch();
batch.executeBatch();
▶ Preview
INSERT → executeUpdate()
UPDATE → executeUpdate()
Batch → addBatch() + executeBatch()
Always use ? placeholders for user input
