while checks before executing; do-while executes at least once. W3Schools →

count = 0;

  count++;

Collections

ArrayList is a resizable array implementation of the List interface. W3Schools →
ArrayList
List<Integer> nums = new ArrayList<>();

nums.add(2);
nums.add(5);
nums.add(8);
System.out.println(nums.get(0)); // 2

for (int i = 0; i < nums.size(); i++) {
  System.out.print(nums.get(i) + " ");
}
// 2 5 8

nums.remove(nums.size() - 1); // remove last

for (Integer v : nums) {
  System.out.print(v + " ");
}
// 2 5
get(0) = 2
2 5 8 → after remove last: 2 5
