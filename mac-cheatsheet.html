Mac Configuration (Dev Machine Setup)

1 brew 2 defaults 3 ~/.zshrc 4 ssh-keygen
A fresh Mac becomes a dev machine in four short steps, done once: install tools, tweak settings, tune the shell, create keys for GitHub.
1. Install Homebrew — the package manager for macOS. Paste one line into Terminal, then use brew install for command-line tools and brew install --cask for regular apps. brew.sh →
Terminal
# 1. Install Homebrew (one line, from brew.sh)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 2. Apple Silicon Macs: put brew on your PATH (the installer prints this)
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

# 3. Install command-line tools
brew install git node python wget

# 4. Install regular apps (casks)
brew install --cask visual-studio-code iterm2 google-chrome

# 5. Check everything is healthy
brew doctor
What you get
🍺 brew install git → git --version works in any new terminal window
📦 Formula = command-line tool · Cask = app that lands in /Applications
🔍 Not sure of a name? brew search node
⬆️ Keep things fresh: brew update && brew upgrade
🗑️ Remove: brew uninstall wget
2. Tweak System Settings — most options live in Apple menu → System Settings. Hidden ones can be flipped from the terminal with defaults write, then restarting the app that owns them.
defaults write
# Finder: show hidden files and all file extensions
defaults write com.apple.finder AppleShowAllFiles -bool true
defaults write NSGlobalDomain AppleShowAllExtensions -bool true

# Keyboard: faster key repeat (lower = faster)
defaults write NSGlobalDomain KeyRepeat -int 2
defaults write NSGlobalDomain InitialKeyRepeat -int 15

# Dock: auto-hide and smaller icons
defaults write com.apple.dock autohide -bool true
defaults write com.apple.dock tilesize -int 40

# Screenshots: save to ~/Screenshots instead of the Desktop
mkdir -p ~/Screenshots
defaults write com.apple.screencapture location ~/Screenshots

# Apply: restart the apps that own those settings
killall Finder; killall Dock; killall SystemUIServer
Settings app vs. terminal
⚙️ GUI: Apple menu → System Settings → Keyboard → Key repeat rate
⌨️ The terminal does the same thing, and you can script it for your next Mac
👀 Check a value: defaults read com.apple.dock autohide
↩️ Undo a tweak: defaults delete com.apple.dock autohide
⚠️ Keyboard changes need a log out / log in to take effect
3. Set up the terminal — macOS already uses zsh. Everything you add to ~/.zshrc (a plain text file in your home folder) runs each time a terminal opens: aliases, PATH, editor.
~/.zshrc
# Which shell am I using? (should print /bin/zsh)
echo $SHELL

# Open your config in a text editor (creates it if missing)
open -e ~/.zshrc        # TextEdit
nano ~/.zshrc           # or inside the terminal

# ---- paste into ~/.zshrc ----
export PATH="$HOME/bin:$PATH"      # find your own scripts
export EDITOR="code --wait"        # git opens VS Code
alias ll='ls -la'
alias gs='git status'
alias ..='cd ..'
autoload -Uz compinit && compinit    # tab completion

# Reload without opening a new window
source ~/.zshrc
Dotfiles explained
📄 Files starting with . are hidden — ls -la shows them
🏠 ~ is your home folder, so ~/.zshrc = /Users/you/.zshrc
⚡ Type ll and zsh runs ls -la for you
🎨 Optional extras: Oh My Zsh (themes & plugins), brew install --cask iterm2
💾 Keep a copy of ~/.zshrc in a git repo to reuse on your next Mac
4. Create SSH keys for GitHub — an SSH key pair lets you git push without typing a password. The private key stays on your Mac; the public key (.pub) goes to GitHub. GitHub Docs →
ssh-keygen
# 1. Make a key pair (press Return for the default path, pick a passphrase)
ssh-keygen -t ed25519 -C "you@example.com"

# 2. Start the agent and remember the key in Keychain
eval "$(ssh-agent -s)"
ssh-add --apple-use-keychain ~/.ssh/id_ed25519

# 3. Tell SSH to use it for GitHub  (put this in ~/.ssh/config)
Host github.com
  AddKeysToAgent yes
  UseKeychain yes
  IdentityFile ~/.ssh/id_ed25519

# 4. Copy the PUBLIC key, then paste it on GitHub
pbcopy < ~/.ssh/id_ed25519.pub

# 5. Test the connection
ssh -T git@github.com
On GitHub
🌐 github.com → profile photo → Settings → SSH and GPG keys → New SSH key → paste
✅ Success looks like: Hi you! You've successfully authenticated...
🔐 id_ed25519 = private (never share) · id_ed25519.pub = public (safe to paste)
🔗 Clone with SSH: git clone git@github.com:user/repo.git

Trackpad Gestures

→ 🖼️
Gestures are shortcuts for your fingers. Two fingers sliding across the pad scroll a page; three fingers swipe to the next desktop.
Multi-touch trackpad gestures for navigation and productivity.
Gestures

2-finger tap           Right-click
2-finger pinch         Zoom in/out
3-finger swipe up      Mission Control

4-finger pinch         Launchpad

👆 Enable tap to click: Trackpad → Point & Click → Tap to click

Text Editing Shortcuts

Option hops words
⌥→ (Option + arrow) jumps the cursor one whole word at a time; hold ⇧ (Shift) too and it selects as it goes.
Text navigation and editing shortcuts that work in most macOS apps.
Cursor Movement
Option+←      Move to previous word
Option+→      Move to next word
Cmd+←         Move to beginning of line
Cmd+→         Move to end of line
Cmd+↑         Move to beginning of document
Cmd+↓         Move to end of document

# Selection (add Shift to any above)
Shift+Option+←  Select previous word
Shift+Cmd+↑    Select to beginning of document

# Deletion
Option+Delete   Delete previous word
Cmd+Delete    Delete to beginning of line
Pro Tips
🎯 Option moves by word — Cmd moves by line/document
➕ Add Shift to any movement shortcut to extend selection
✂️ Ctrl+K deletes from cursor to end of line (in terminal)
🔄 Cmd+Z undo, Cmd+Shift+Z redo
