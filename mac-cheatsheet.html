General macOS Shortcuts

Essential system-wide keyboard shortcuts every Mac user should know.
System Shortcuts
Cmd+Space      Spotlight search
Cmd+Tab         Switch between apps
Cmd+`          Switch windows of same app
Cmd+Q           Quit active app
Cmd+W           Close current window
Cmd+H           Hide active app
Cmd+Option+H  Hide all other apps
Cmd+Option+Esc  Force Quit dialog
Cmd+Shift+Q  Lock screen
Ctrl+Cmd+Q   Lock screen immediately
Cmd+Shift+.  Show hidden files in open dialogs
Pro Tips
🔍 Cmd+Space opens Spotlight — use it as a calculator, currency converter, and app launcher
🔄 Cmd+Tab then ↓ or ↑ to select visible windows
🚫 App won't quit? Cmd+Option+Esc is the nuclear option
🔐 Ctrl+Cmd+Q locks screen instantly

Finder & File Management

Navigate, organize, and manage files efficiently in Finder.
Finder Shortcuts
Cmd+N           New Finder window
Cmd+T           New tab
Cmd+Shift+N   New folder
Cmd+I           Get Info
Cmd+Delete      Move to Trash
Cmd+Shift+Delete  Empty Trash
Cmd+Option+V   Move file here (after Copy)
Cmd+↓         Open selected item
Cmd+↑         Go to parent folder
Cmd+3           Column view
Cmd+Shift+G   Go to folder (type path)
Space           Quick Look preview
Pro Tips
📂 Cmd+Shift+G — type or paste any path to jump there
📋 Cmd+C then Cmd+Option+V = move file
👁️ Space on a file = instant preview (images, PDFs, video, code)
🏷️ Drag a file onto a Finder tab to move it there

Screenshots & Screen Recording

Capture screen content using built-in macOS screenshot tools.
Screenshot Shortcuts
Cmd+Shift+3         Full screen capture
Cmd+Shift+4         Select area capture
Cmd+Shift+4+Space  Capture specific window
Cmd+Shift+5         Screenshot toolbar
Ctrl+ any above     Save to clipboard instead of file
Pro Tips
📋 Add Ctrl to any screenshot shortcut to copy to clipboard
🎬 Cmd+Shift+5 opens the toolbar with screen recording options
✏️ Click screenshot thumbnail to annotate before saving
🔄 Cmd+Shift+5 → Options → set save location

# Flush DNS cache
sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder

defaults write com.apple.finder AppleShowAllFiles YES
# Battery info
pmset -g batt

Trackpad Gestures

Multi-touch trackpad gestures for navigation and productivity.
Gestures
2-finger scroll        Scroll up/down/left/right
2-finger tap           Right-click
2-finger pinch         Zoom in/out
3-finger swipe up      Mission Control
3-finger swipe down    Show all windows (Exposé)
3-finger swipe left/right  Switch desktops / full-screen apps
4-finger pinch         Launchpad
4-finger spread        Show desktop
Tap with 2 fingers     Secondary click (right-click)
Tap with 3 fingers     Look up word / data detector
Settings
⚙️ System Settings → Trackpad → Point & Click, Scroll & Zoom, More Gestures
🔄 Change 3-finger drag: Accessibility → Pointer Control → Trackpad Options
👆 Enable tap to click: Trackpad → Point & Click → Tap to click

Mission Control & Spaces

Manage multiple desktops (Spaces) and full-screen apps efficiently.
Desktop Management
Ctrl+↑           Mission Control
Ctrl+↓           Show active app windows (Exposé)
Ctrl+←           Switch to left desktop
Ctrl+→           Switch to right desktop
Ctrl+1-9         Go to specific desktop
Cmd+Option+D    Show/hide Dock
F11 or Cmd+F3  Show desktop
Drag window to edge    Create new desktop (in Mission Control)
Pro Tips
📌 Assign apps to specific desktops: right-click app in Dock → Options → Assign To
🔄 Drag windows to top edge in full-screen to access menu bar
🗂️ Ctrl+Number jumps directly to that desktop

Text Editing Shortcuts

Text navigation and editing shortcuts that work in most macOS apps.
Cursor Movement
Option+←      Move to previous word
Option+→      Move to next word
Cmd+←         Move to beginning of line
Cmd+→         Move to end of line
Cmd+↑         Move to beginning of document
Cmd+↓         Move to end of document

# Selection (add Shift to any above)
Shift+Option+←  Select previous word
Shift+Cmd+↑    Select to beginning of document

# Deletion
Option+Delete   Delete previous word
Cmd+Delete    Delete to beginning of line
Pro Tips
🎯 Option moves by word — Cmd moves by line/document
➕ Add Shift to any movement shortcut to extend selection
✂️ Ctrl+K deletes from cursor to end of line (in terminal)
🔄 Cmd+Z undo, Cmd+Shift+Z redo
