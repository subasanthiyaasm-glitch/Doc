File Operations

Create, copy, move, and delete files & directories with touch, mkdir, cp, mv, and rm. W3Schools →
Create, Copy, Move, Delete
$ touch file.txt
$ mkdir -p a/b/c
$ cp source.txt dest.txt
$ mv old.txt new.txt
$ rm file.txt
$ rm -rf dirname
touch — create empty file
mkdir -p — create parent dirs
cp — copy file
mv — move or rename
rm — remove file
rm -rf — remove directory recursively
View files with cat, less, head, tail; count with wc; create symlinks with ln; check disk usage with du. W3Schools →

$ head -n 5 file.txt
$ tail -f file.txt
$ wc -l file.txt
$ ln -s target link
$ du -sh dir
cat — print entire file
less — scroll through file
head -5 — first 5 lines
tail -f — follow live output
wc -l file.txt → 42
ln -s — symbolic link
du -sh dir → 1.2M

Pipes & Redirection

Redirect stdout/stdin/stderr with >, >>, 2>&1; pipe commands with |; chain with &&, ||, ;. W3Schools →
Redirection & Pipes
$ echo "data" > file.txt
$ echo "more" >> file.txt
$ cmd 2>&1
$ cmd1 | cmd2
$ cmd1 | xargs cmd2
$ make && make install
$ false || echo "fallback"
$ cmd1 ; cmd2
> — redirect stdout to file (overwrite)
>> — append stdout to file
2>&1 — merge stderr into stdout
| — pipe stdout to next command
xargs — build args from stdin
&& — run next only if previous succeeds
|| — run next only if previous fails
; — always run next regardless

Variables

Set and use shell variables, environment variables, special variables, and command substitution. W3Schools →
Variables

NAME="value" — set variable

export — make available to child processes
$? — exit code of last command (0 = success)
$HOME /Users/john
$USER john
$(command) — command substitution
${var:-default} — use default if var unset

Scripting

Write shell scripts with shebang, conditionals, loops, case statements, functions, and arguments. W3Schools →
Shebang, Conditionals & Loops

if [ $1 -eq 5 ]; then
  echo "is five"
fi

for i in {1..5}; do
  echo $i
done

  echo $line
done < file.txt

Use case for pattern matching, function for reusable code, and $1, $@, $# for script arguments. W3Schools →
Case, Functions & Arguments
case $var in
  start) echo "Starting" ;;
  stop)  echo "Stopping" ;;
  *)     echo "Unknown" ;;
esac

function greet() {
  echo "Hello, $1"
}
greet "World"

# $1 $2 ... positional args
# $@ all args, $# arg count
case — pattern matching
var=start → "Starting"

function name() { ... }
greet "World" → Hello, World

$1, $2 — positional arguments
$@ — all arguments
$# — argument count
