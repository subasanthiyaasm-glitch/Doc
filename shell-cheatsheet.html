A command is just a small program. You type it after the $ prompt, the shell launches it as a process, and whatever it prints comes back to your screen.

| The pipe — pass output into the next command
ls
grep notes → notes.txt

cmd1 | cmd2 takes the output of the first command and feeds it straight into the second.

> The redirect — save output to a file
ls
📄 files.txt

cmd > file sends the output into a file instead of showing it on the screen.

Processes

View running processes with ps and top; send signals with kill; manage background jobs with bg, fg. W3Schools →
ps, top, kill
$ ps aux                 # all running processes
$ ps aux | grep node     # filter by name
$ top                    # live process monitor
$ top -u john           # top for a specific user

$ kill 1234             # SIGTERM — graceful stop
$ kill -9 1234          # SIGKILL — force kill
$ kill -15 1234         # SIGTERM explicit
$ kill -1 1234          # SIGHUP — reload config
$ killall node           # kill all by name
$ pkill -f "my-app"    # kill by pattern

$ cmd &                 # run in background
$ jobs                  # list background jobs
$ fg %1                 # bring job 1 to foreground
$ bg %1                 # resume job 1 in bg
Common signals:
 1 SIGHUP — reload config
 2 SIGINT — Ctrl+C interrupt
 9 SIGKILL — force kill (cannot be caught)
15 SIGTERM — graceful shutdown (default)

top keyboard shortcuts:
q — quit     k — kill a PID
M — sort by memory usage
P — sort by CPU usage
u — filter by user
? — help

Permissions

Change permissions with chmod, ownership with chown, default mask with umask; view with ls -l. W3Schools →
chmod, chown, umask
$ chmod 755 script.sh    # set by octal
$ chmod +x script.sh    # add execute for all
$ chmod u+w file        # user: add write
$ chmod go-w file       # group+other: remove write
$ chmod a=r file        # all: set read only
$ chmod -R 755 dir/     # recursive
$ chown john:dev file.txt
$ chown -R john:dev dir/
$ umask                  # current default mask
$ umask 022             # new files get 644
$ ls -l
-rwxr-xr-x 1 john staff script.sh
Symbolic: u/g/o/a ± r/w/x
u=user  g=group  o=other  a=all
+ add    - remove   = set exact

ls -l column layout:
-rwxr-xr-x 1 john staff 1024 file
^^^^^^^^^^ ^^ ^^^^ ^^^^^^ ^^^^
perms links user group size
Each slot is read, write, execute — on or off
r w x = 7
Each permission digit is the sum of r=4 w=2 x=1. Three digits cover user, group, other — e.g. chmod 755 = user rwx(7), group r-x(5), other r-x(5). W3Schools →
Permission Chart (octal reference)
# Octal  Symbolic    User  Group Other  Typical use
777     rwxrwxrwx   rwx   rwx   rwx   # all full (avoid!)
755     rwxr-xr-x   rwx   r-x   r-x   # executables, dirs
750     rwxr-x---   rwx   r-x   ---   # restricted exec
700     rwx------   rwx   ---   ---   # owner-only exec
664     rw-rw-r--   rw-   rw-   r--   # group can write
644     rw-r--r--   rw-   r--   r--   # regular files std
640     rw-r-----   rw-   r--   ---   # private readable
600     rw-------   rw-   ---   ---   # private file
400     r--------   r--   ---   ---   # read-only
000     ---------   ---   ---   ---   # no access

# Digit → bits: 7=rwx  6=rw-  5=r-x  4=r--  0=---
Bit decoder   r=4   w=2   x=1
Digit Sym Read Write Exec
7 rwx ✓ ✓ ✓
6 rw- ✓ ✓ ✗
5 r-x ✓ ✗ ✓
4 r-- ✓ ✗ ✗
2 -w- ✗ ✓ ✗
1 --x ✗ ✗ ✓
0 --- ✗ ✗ ✗

chmod 755 = User(7) Group(5) Other(5)
d rwx r-x r-x → directory 755

Bash Scripting Basics

A script is just commands saved in a file. Start with a #!/usr/bin/env bash shebang, store values in variables, and read them back with "$var" or $(command). W3Schools →
Shebang, variables & substitution
#!/usr/bin/env bash
name="Ada"              # set a variable (no spaces around =)
echo "Hi, $name"      # always quote "$var"
today=$(date +%F)   # $(...) command substitution
echo "Today is $today"
$ bash greet.sh
Hi, Ada
Today is 2026-10-26

#!/usr/bin/env bash → finds bash on PATH
"$name" → quotes keep spaces safe
$(cmd) → runs cmd, drops in its output
Branch with if/then/fi, repeat with for and while, and bundle reusable steps into a function that reads arguments via $1. W3Schools →
if / for / while / functions
if [ "$1" = "hi" ]; then
  echo "hello"
fi

for f in *.txt; do
  echo "$f"
done

n=1
while [ $n -le 3 ]; do
  echo "$n"
  n=$((n+1))
done

greet() {
  echo "Hi, $1"
}
greet "Ada"
if … then … fi — run block when test is true
for f in *.txt — loop over matching files
while [ … ] — loop while test stays true
n = 1 → 2 → 3, then stops
greet() { … } — define once, call anytime
greet "Ada" → Hi, Ada
A script runs top-to-bottom — one line at a time
▸
  1. #!/usr/bin/env bash
  2. name="Ada"
  3. echo "Hi, $name"
  4. for i in 1 2 3; do
  5.   echo $i
  6. done
