# Multi-Language Cheatsheet

A collection of quick-reference cheatsheets with live previews for HTML, CSS, JavaScript, Java, C, Python, PostgreSQL, Shell, VS Code, AI tools (OpenCode, ChatGPT, Gemini, Claude), and macOS.

## Adding a New Language

### 1. Create the HTML page

Copy an existing page (e.g., `java-cheatsheet.html`) as a template:

```bash
cp java-cheatsheet.html yourlang-cheatsheet.html
```

Edit the new file:

| What | Change to |
|------|-----------|
| `<title>` | `"YourLang &mdash; Cheatsheet"` |
| `<h1>` | `YourLang` |
| `renderHeader('YourLang')` | Match your language ID |
| TOC links | Match your section IDs |
| Section content | Replace with your language's examples |

### 2. Tab bar format

The tab bar is auto-generated by `js/header.js`. Each page has:

```html
<nav class="tab-bar" id="tab-bar"></nav>
<script src="js/header.js"></script>
<script>renderHeader('YourLang')</script>
```

The `renderHeader()` function builds the tab bar and marks the active tab. To add a new language, edit `js/header.js` and add it to the `LANGUAGES` array:

```js
{ id: 'YourLang', href: 'yourlang-cheatsheet.html', icon: '🔤' }
```

The icon can be any emoji. The tab bar updates on **all pages** automatically.

### 3. Cheat-block structure

Each example uses a split-panel layout:

```html
<div class="block-desc">
  <span>Brief 1-sentence explanation. Use <code>code</code> for inline syntax.</span>
  <a class="w3-link" href="https://www.w3schools.com/..." target="_blank">W3Schools →</a>
</div>
<div class="cheat-block">
  <div class="code-panel">
    <div class="panel-label">Topic</div>
    <pre>code here</pre>
  </div>
  <div class="live-panel">
    <div class="live-output">rendered output</div>
  </div>
</div>
```

- `.block-desc` — full-width explanation row with optional W3Schools link
- `.code-panel` — dark theme, shows source code
- `.live-panel` — white/light background, shows rendered result

### 4. Syntax highlighting classes

Use these span classes in `<pre>` blocks:

| Class | Purpose |
|-------|---------|
| `c` | Comments / blue accent text |
| Use inline spans with color classes matching your language's style |

For custom languages, add a `<style>` block in `<head>` with your highlighting colors.

### 5. Update all existing pages

Every existing page's tab bar must include the new language link. Run:

```bash
# Check all tab bars are in sync
rg 'class="tab-bar"' -A8 *.html
```

### 6. W3Schools reference links

Every `.cheat-block` should have a `.block-desc` above it with a W3Schools link pointing to the relevant tutorial page. Use language-specific W3Schools paths:

- `https://www.w3schools.com/html/...`
- `https://www.w3schools.com/css/...`
- `https://www.w3schools.com/js/...`
- `https://www.w3schools.com/java/...`
- `https://www.w3schools.com/c/...`
- `https://www.w3schools.com/python/...`
- `https://www.w3schools.com/sql/...`
- `https://www.w3schools.com/linux/...` (Shell)
- `code.visualstudio.com/docs` (VS Code)

### 7. Shared assets

| File | Purpose |
|------|---------|
| `css/style.css` | Global styles with CSS custom properties for dark/light theme |
| `js/header.js` | Language list & tab bar generator — single source of truth for nav |
| `js/script.js` | Search, filter, keyboard shortcuts, theme toggle, fetch demos |

To add a new language, edit `js/header.js` only — all pages automatically pick up the new tab.
