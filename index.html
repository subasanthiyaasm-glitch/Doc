Getting Started

Basic HTML5 document structure with <!doctype html>, <html>, <head>, and <body> elements. W3Schools →

Every page nests the same way: a doctype, then html wrapping a head and a body.

hello.html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta http-equiv="X-UA-Compatible" content="IE=edge" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>HTML5 Boilerplate</title>
  </head>
  <body>
    <h1>Hello world, hello CheatSheets.zip!</h1>
  </body>
</html>

HTML Links

The <a> tag creates hyperlinks to URLs, email addresses with mailto:, phone numbers with tel:, and SMS with sms:. W3Schools →

How a link works: an <a href> points at another page. Click it and the browser opens that target — A opens B, B opens C, until a link points nowhere (null).

<a href="https://cheatsheets.zip">CheatSheets</a>
<a href="mailto:jack@abc.com">Email</a>
<a href="tel:+12345678">Call</a>
<a href="sms:+12345678&body=ha%20ha">Msg</a>

CheatSheets   Email   Call   Msg

AttributeDescription
hrefThe URL that the hyperlink points to
relRelationship of the linked URL
targetLink target location: _self, _blank, _top, _parent

HTML Tables

The <table> element structures tabular data with rows (<tr>), header (<thead>), and body (<tbody>) sections. W3Schools →

Rows and columns: a header row (<th>) over body cells (<td>) inside each <tr>.

<table>
  <thead>
    <tr>
      <td>name</td>
      <td>age</td>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Roberta</td>
      <td>39</td>
    </tr>
    <tr>
      <td>Oliver</td>
      <td>25</td>
    </tr>
  </tbody>
</table>
nameage
Roberta39
Oliver25

<table>Defines a table

<td>Defines a cell in a table
<caption>Defines a table caption
<colgroup>Defines a group of columns
<col>Defines a column within a table

<tbody>Groups the body content
<tfoot>Groups the footer content

HTML Forms

The <form> element collects user input with labelled fields like email, password, checkbox, and a submit button. W3Schools →
Submit

Collect, then send: type into an <input>, then <input type="submit"> sends the form.

<form method="POST" action="api/login">
  <label for="mail">Email:</label>
  <input type="email" id="mail" name="mail" />
  <label for="pw">Password:</label>
  <input type="password" id="pw" name="pw" />
  <input type="submit" value="Login" />
  <input type="checkbox" id="ck" name="ck" />
  <label for="ck">Remember me</label>
</form>
AttributeDescription
nameName of form for scripting
actionURL of form script
methodHTTP method, POST / GET (default)
enctypeMedia type
onsubmitRuns when the form was submit
onresetRuns when the form was reset

HTML Meta Tags

The <meta> tag defines page metadata like character set, viewport, and Open Graph / Twitter card properties. W3Schools →

Behind the scenes: <meta> tags feed the tab title and the preview card shown when a page is shared.

<meta charset="utf-8" />

<title>...</title>
<meta property="og:title" content="..." />
<meta name="twitter:title" content="..." />

<meta name="description" content="..." />
<meta property="og:description" content="..." />

<meta name="viewport" content="width=device-width" />

⚠ Meta tags go in the <head> and are not rendered visually.

PropertyExample
og:typewebsite
og:localeen_CA
og:titleHTML cheatsheet
og:urlhttps://cheatsheets.zip/html
og:imagehttps://xxx.com/image.jpg
og:site_nameName of your website
og:descriptionDescription of this page
