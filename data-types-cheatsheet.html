Data Types

What each kind of value holds, why it exists, and where you meet it — explained from zero

What is it? Integer Float / Decimal Boolean Character String Date & Time Array / List Map / Dict Null / None

What Is a Data Type?

A data type is the kind of value a box can hold — a value of the right kind drops in and is accepted, a value of the wrong kind is rejected. Docs →
Matching value → stored safely Mismatched value → error / rejected
Declaring the type tells the computer how much memory to reserve, what operations are allowed (you can add numbers but not add two dates), and catches mistakes early. Docs →

Integer

A whole number with no fractional part — positive, negative, or zero. Docs →
same type, five languages
// C
int count = 42;

// Java
int count = 42;

# Python
count = 42

// JavaScript
let count = 42;

-- SQL
count INTEGER
▶ In action

Why you need it: counting things that can't be split.

Real-world: a shopping cart holding 3 items, never 3.5.

Floating-point / Decimal

A number that can carry a fractional part after the decimal point. Docs →
same type, five languages
// C
double price = 19.99;

// Java
double price = 19.99;

# Python
price = 19.99

// JavaScript
let price = 19.99;

-- SQL
price DECIMAL(10,2)
▶ In action

Why you need it: measuring amounts that fall between whole numbers.

Real-world: a price tag of $19.99 or a body temperature of 36.6°C.

Boolean

A value that is only ever true or false — a yes/no switch. Docs →
same type, five languages
// C  (needs <stdbool.h>)
bool is_active = true;

// Java
boolean isActive = true;

# Python
is_active = True

// JavaScript
let isActive = true;

-- SQL
is_active BOOLEAN
▶ In action

Why you need it: storing an on/off decision to branch logic.

Real-world: a "Remember me" checkbox, or whether a user is logged in.

Character

A single letter, digit, or symbol — one slot holding exactly one character. Docs →
same type, five languages
// C
char grade = 'A';

// Java
char grade = 'A';

# Python (no char type: length-1 str)
grade = 'A'

// JavaScript (no char type: length-1 string)
let grade = 'A';

-- SQL
grade CHAR(1)
▶ In action

Why you need it: handling a value that is a single symbol.

Real-world: a letter grade 'A', or 'Y'/'N' for a one-key answer.

String / Text

A sequence of characters strung together to form words and sentences. Docs →
same type, five languages
// C  (array of chars)
char name[] = "Ada";

// Java
String name = "Ada";

# Python
name = "Ada"

// JavaScript
let name = "Ada";

-- SQL
name VARCHAR(50)
▶ In action

Why you need it: storing any human-readable text.

Real-world: a username, an email address, or this sentence.

Date & Time

A value representing a point in time — a date, a clock time, or both. Docs →
same type, five languages
// C  (seconds since 1970)
time_t now = time(NULL);

// Java
LocalDate d = LocalDate.now();

# Python
import datetime
d = datetime.date.today()

// JavaScript
let now = new Date();

-- SQL
created_at TIMESTAMP
▶ In action

Why you need it: recording and comparing when things happen.

Real-world: an order's timestamp, or a calendar event's start.

Array / List

An ordered collection of values, reached by position (its index). Docs →
same type, five languages
// C
int nums[3] = {1, 2, 3};

// Java
int[] nums = {1, 2, 3};

# Python (list)
nums = [1, 2, 3]

// JavaScript
let nums = [1, 2, 3];

-- SQL (Postgres array)
nums INTEGER[]
▶ In action

Why you need it: keeping many related values in a known order.

Real-world: a to-do list, or the songs in a playlist.

Map / Dictionary (key-value)

A collection that looks up a value by a unique key, like a word in a dictionary. Docs →
same type, five languages
// C  (no built-in: use a struct / library)

// Java
Map<String, Integer> ages = new HashMap<>();
ages.put("Ada", 36);

# Python (dict)
ages = {"Ada": 36}

// JavaScript (object / Map)
let ages = { "Ada": 36 };

-- SQL (key-value via JSONB)
ages JSONB
▶ In action

Why you need it: instant lookup of a value by a meaningful name.

Real-world: a phone's contacts — a name maps to a number.

Null / None

A special value meaning "no value here" — an empty, deliberately-unset box. Docs →
same type, five languages
// C  (null pointer)
char *name = NULL;

// Java
String name = null;

# Python
name = None

// JavaScript (null or undefined)
let name = null;

-- SQL
name VARCHAR NULL
▶ In action

Why you need it: marking "unknown" or "not filled in yet" distinctly from zero.

Real-world: a profile with no middle name, or a form field left blank.
