How JavaScript Runs

JavaScript does one thing at a time. The Call Stack runs your code line by line. Slow work (like a timer or a network request) is handed to the Web APIs so your page never freezes. When that work finishes, its callback waits in the Callback Queue, and the Event Loop pushes it back onto the stack to run. Watch one task travel the loop.

Conditionals

A condition routes the flow one way or the other: true takes the green path, false the red.

Execute different code blocks based on boolean conditions using if, else if, and else. W3Schools →
if / else if / else
const size = 10;

if (size > 100) {
  console.log('Big');
} else if (size > 20) {
  console.log('Medium');
} else if (size > 4) {
  console.log('Small');
} else {
  console.log('Tiny');
}
> Small
Write a compact conditional expression with condition ? exprIfTrue : exprIfFalse. W3Schools →
Ternary Operator
let x = 1;
let result = x == 1 ? true : false;
// condition ? exprIfTrue : exprIfFalse
> true
Match a value against multiple case clauses for clean multi-way branching. W3Schools →
switch Statement

switch (food) {
  case 'pizza':
    console.log('A delicious pie');
    break;
  default:
    console.log('Enjoy your meal');
}
> Enjoy your meal

Functions

A value goes in, the function transforms it, and a new value comes out.

Define reusable functions using declarations or store them as expressions in variables. W3Schools →
Declaration & Expression
// Function declaration
function sum(a, b) { return a + b; }

// Function expression
const sum = function(a, b) {
  return a + b;
};
> sum(3, 6) = 9
Write concise functions with => syntax, omitting function and return for single expressions. W3Schools →
Arrow Functions (ES6)
// Two params
const sum = (a, b) => a + b;

// Single param
const double = x => x * 2;

// No params

> sum(2, 30) = 60
> double(5) = 10

function noReturn() { }

Scope

Inner code can read outward into the outer scope — but the outside can't see in.

let is block-scoped and safer than var, which is function-scoped and can cause bugs. W3Schools →
let vs var
// let: block-scoped
for (let i = 0; i < 3; i++) { }
// i not accessible here ❌

// var: function-scoped
for (var j = 0; j < 3; j++) { }
// j accessible here ✔️

let is scoped to the nearest block; var to the nearest function.

Variables declared outside any block are global; those inside {} are block-scoped with let/const. W3Schools →
Global & Block Scope
const color = 'blue'; // global

if (true) {
  const msg = 'Logged in'; // block
}
// msg not accessible here ❌
> blue (global accessible everywhere)

Arrays

Items sit at numbered slots; push() adds to the end and pop() removes it again.

Create ordered lists with [ ] and access elements by their zero-based index. W3Schools →
Creating & Accessing
const fruits = ['apple', 'orange', 'banana'];
const mixed = [1, 'chicken', false];

fruits[0];   // 'apple'
fruits.length; // 3
> fruits[0] = "apple"
> fruits.length = 3
Modify arrays in-place using push(), pop(), unshift(), and shift(). W3Schools →
Mutating Methods
const arr = [1, 2];
arr.push(3, 4);      // [1,2,3,4]  (end)
arr.pop();           // [1,2,3]    (remove end)
arr.unshift(0);      // [0,1,2,3]  (start)
arr.shift();         // [1,2,3]    (remove start)
push → add to end   pop → remove end
unshift → add to start   shift → remove start
Merge arrays without mutation using concat(), or unpack values with destructuring [a, b] = arr. W3Schools →
concat & Destructuring
// Non-mutating merge
[1, 2].concat([3, 4]); // [1,2,3,4]

// Destructuring
const [name, age] = ['John', 8];
// name='John', age=8
> [1,2,3,4]   name="John"   age=8

Set

A Set keeps only unique values — a duplicate is turned away at the door.

Store unique values of any type with Set and use add(), has(), delete(), and clear(). W3Schools →
Set Methods
const s = new Set([1, true, 'a']);

s.add('b');        // add value
s.has('a');        // true
s.delete('a');     // remove
s.size;            // 3
s.clear();         // remove all
> s.has('a') = true   s.size = 3

Loops

A loop runs the same body again and again, stepping i each time until the test fails.

Repeat code with for, while, or do...while loops, controlling flow with break and continue. W3Schools →
for / while / do...while
// for
for (let i = 0; i < 3; i++) { }

// while
while (condition) { }

// do...while
do { } while (condition);

// break / continue
for (let i = 0; i < 10; i++) {
  if (i === 3) continue;
  if (i > 5) break;
}
> 0 1 2 4 5 (continue skips 3, break stops at 5)
Iterate over object keys with for...in or over iterable values with for...of. W3Schools →
for...in / for...of
const fruits = ['apple', 'orange'];

// for...in → indexes
for (let i in fruits) { }

// for...of → values
for (let f of fruits) { }
for...in → "0", "1"   for...of → "apple", "orange"

Iterators

map() walks the array and builds a new one, transforming every item (here, ×2).

Pass a function as an argument to another function to be called later. W3Schools →
Callback Functions
const isEven = (n) => n % 2 == 0;

const printMsg = (fn, num) => {
  console.log(fn(num));
};

printMsg(isEven, 4); // true
> true
Transform arrays with map(), filter with filter(), and accumulate with reduce(). W3Schools →
map / filter / reduce
// map - transform each
[1,2,3].map(x => x * 2); // [2,4,6]

// filter - keep matches
[4,11,42].filter(n => n > 5); // [11,42]

// reduce - accumulate
[1,2,3,4].reduce((a, c) => a + c); // 10
map → [2,4,6]   filter → [11,42]   reduce → 10

forEach

Classes

A class is a blueprint; new stamps out as many instances as you like.

Create object blueprints with class and initialize instances with constructor. W3Schools →
Class & Constructor
class Song {
  constructor(title, artist) {
    this.title = title;
    this.artist = artist;
  }
  play() { console.log('Playing!'); }
}

const mySong = new Song('Bohemian Rhapsody', 'Queen');
> mySong.title = "Bohemian Rhapsody"
> mySong.play() = "Playing!"
Inherit properties and methods from a parent class using extends and super. W3Schools →
extends (Inheritance)
class Media {
  constructor(info) {
    this.publishDate = info.publishDate;
  }
}

class Song extends Media {
  constructor(songData) {
    super(songData);
    this.artist = songData.artist;
  }
}

extends creates a child class that inherits from a parent.

Define methods on the class itself (not instances) using the static keyword. W3Schools →
Static Methods
class Dog {
  static bark() { console.log('Woof!'); }
}

Dog.bark(); // static call
> Woof!

Modules

One file exports code; another imports it — the piece travels between them.

Share code between files using export and import with ES6 module syntax. W3Schools →
Export / Import (ES6)
// myMath.js
export default function add(a, b) {
  return a + b;
}
export function subtract(a, b) {
  return a - b;
}

// main.js
import add, { subtract } from './myMath.js';
> add(6, 2) = 8   subtract(6, 2) = 4
Export and import modules in Node.js using module.exports and require(). W3Schools →
module.exports / require
// myMath.js (Node.js)
module.exports = { add, subtract, multiply };

// main.js
const myMath = require('./myMath.js');
myMath.add(6, 2); // 8
// Node.js CommonJS
> myMath.add(6, 2) = 8
> myMath.subtract(6, 2) = 4

Promises

A promise starts pending, then settles — resolved to .then(), or rejected to .catch().

Handle asynchronous operations with new Promise() and .then() / .catch(). W3Schools →
Creating & Using Promises
const promise = new Promise((resolve, reject) => {
  const res = true;
  res ? resolve('Resolved!')
      : reject(Error('Error'));
});

promise.then(res => console.log(res))
       .catch(err => console.error(err));
> Resolved!
Run multiple promises in parallel with Promise.all() or wait for all to settle with Promise.allSettled(). W3Schools →
Promise.all & Promise.allSettled
const p1 = Promise.resolve(3);
const p2 = new Promise((res) =>
  setTimeout(() => res(2), 100));

Promise.all([p1, p2]).then(([r1, r2]) => {
  console.log(r1, r2); // 3 2
});

// allSettled returns status for each
> Promise.all = [3, 2]
Transform resolved values by chaining multiple .then() calls sequentially. W3Schools →
Chaining .then()
Promise.resolve('*')
  .then(s => s + s)
  .then(s => s + '.')
  .then(console.log); // "**."
> "**."

Async / Await

await pauses the function until the promise is ready, then execution resumes.

Write asynchronous code that reads like synchronous code using async and await. W3Schools →
Async Function & Await
function helloWorld() {
  return new Promise(res =>
    setTimeout(() => res('Hello World!'), 200)
  );
}

async function msg() {
  const msg = await helloWorld();
  console.log('Message:', msg);
}
msg(); // after 200ms
> Message: Hello World!
Catch and handle runtime errors gracefully with try, catch, and optionally finally. W3Schools →
Error Handling (try/catch)
let json = '{ "age": 30 }';

try {
  let user = JSON.parse(json);
  console.log(user.name); // no name!
} catch (e) {
  console.error('Invalid JSON');
}
> undefined (no "name" property, no error)

Use fetch() with async/await and try/catch for cleaner async HTTP code. W3Schools →
Fetch with async/await
async function getUser(id) {
  try {
    const res = await fetch(
      `https://jsonplaceholder.typicode.com/users/${id}`
    );
    if (!res.ok) throw new Error('Failed');
    const user = await res.json();
    console.log(user.name, user.email);
  } catch (e) {
    console.error(e.message);
  }
}
getUser(1);
// Leanne Graham, Sincere@april.biz
