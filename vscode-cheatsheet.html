How It Works: Shortcuts That Speed You Up

New to VS Code? The big idea: you press a shortcut and the editor does a whole job for you — runs a command, edits several places at once, swaps every match, or opens a terminal. Watch the four scenes loop below. Tips & Tricks →

You press ⌘⇧P → VS Code reacts — one keystroke, one visible effect. Four everyday examples:

1Command Palette ⌘⇧P

Type what you want to do — every command is one search away, no menus.

2Multi-Cursor ⌘D

Each press selects the next match. Type once and it lands in every spot.

3Search & Replace ⌘H

Matches light up as you type; Replace All swaps them in one go.

4Terminal ⌃`

A shell slides up under your code — run commands without leaving the window.

On Windows and Linux swap ⌘ for Ctrl and ⌥ for Alt. The pattern never changes: a shortcut you can press in a second replaces a mouse journey you would otherwise repeat all day.
